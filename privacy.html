เก็บข้อมูลอะไรบ้าง

  • อีเมล — ใช้เป็นชื่อบัญชี ส่งลิงก์ตั้งรหัสผ่านใหม่ และส่งใบเสร็จเมื่อชำระเงิน
  • ชื่อผู้ใช้ — ที่คุณตั้งเอง ใช้แสดงบนกระดานจัดอันดับ (ปิดได้)
  • ความคืบหน้าการเรียน — คำที่ทบทวน วันเวลาที่ทบทวน และผลที่กด ใช้คำนวณว่าจะเอาคำไหนมาให้ทบทวนวันไหน
  • สถานะสมาชิก — วันหมดอายุ Pro และประวัติการชำระเงิน (เลขที่รายการ ยอดเงิน วิธีจ่าย)

เข้าสู่ระบบด้วย Google, GitHub หรือ Discord

เมื่อคุณเลือกเข้าสู่ระบบด้วยผู้ให้บริการเหล่านี้ เราขอเพียง อีเมลและชื่อโปรไฟล์ เท่านั้น เราไม่ขอสิทธิ์อ่านอีเมล ไฟล์ รายชื่อเพื่อน หรือข้อมูลอื่นใดในบัญชีของคุณ และเราไม่เคยเห็นรหัสผ่านของบัญชีนั้น

ข้อมูลบัตรเครดิต

เลขบัตรไม่เคยผ่านเซิร์ฟเวอร์ของเรา ระบบชำระเงินของ Omise แปลงเป็นโทเคนในเบราว์เซอร์ของคุณโดยตรง เราเก็บเพียงเลขที่รายการและยอดเงินไว้ออกใบเสร็จ

ใครเห็นข้อมูลของคุณบ้าง

ข้อมูลเก็บบน Supabase (ฐานข้อมูล PostgreSQL ที่สิงคโปร์) เปิดอ่านได้เฉพาะบัญชีของคุณเอง บังคับด้วย Row Level Security ในระดับฐานข้อมูล ไม่ใช่แค่ซ่อนในหน้าเว็บ

สิ่งเดียวที่คนอื่นเห็นได้คือ ชื่อผู้ใช้และคะแนนบนกระดานจัดอันดับ ซึ่งปิดได้ในหน้าตั้งค่า เราไม่ขายและไม่แลกเปลี่ยนข้อมูลกับใคร และไม่มีเครื่องมือติดตามโฆษณาในเว็บนี้
